Gerenciamento de Backups da Pasta

Como os sistemas rodam de forma totalmente offline utilizando o armazenamento local (LocalStorage) do seu navegador, recomenda-se compactar a pasta periodicamente ou utilizar o script de backup automatizado para garantir que nenhum dado seja perdido.

Rotina Recomendada

Crie um arquivo compactado (.zip) contendo toda esta pasta do Windows semanalmente e armazene em um drive externo ou nuvem institucional.

Automação por Script

Você pode colocar o arquivo backup.bat na mesma pasta para gerar cópias de segurança instantâneas.
