Manual Operacional do Portal GEDEP

1. Como usar o Acervo Geral

Pesquise pelo campo de busca, filtre clicando nos chips de seção e ordene por ID, título ou status. Marque os checkboxes dos cards para ações em lote (copiar ou enviar para análise pela IA).

2. Ficha ISAD(G)/NOBRADE (19 campos)

Cada documento possui uma ficha arquivística com 19 campos: código de referência, título, data, tipo, dimensão, fundo produtor, história administrativa, história arquivística, procedimento de entrada, âmbito e conteúdo, citação ABNT, arranjo, condições de acesso, originais, observações, link externo e status. Acesse pelo botão "Ficha completa" de cada card.

3. Edição com Delta

Carregue um documento na aba "Edição com Delta", altere apenas o que mudou. Você pode aplicar as alterações diretamente no acervo local com o botão "Aplicar no acervo", ou copiar o prompt diferencial para levar à IA responsável pelo código.

4. Dados (Exportar / Importar)

Exporte o acervo em XLSX ou TXT. Para importar, use um arquivo XLSX gerado pelo próprio portal (o cabeçalho das colunas deve ser preservado). A importação substitui todo o acervo atual.

5. Gerenciar Acervo (sem IA)

Use "Novo documento" (formulário simplificado), "Editar" ou "Excluir" na tabela. Os campos técnicos são preenchidos automaticamente. Ao final da sessão, clique em "Baixar data.js atualizado" e substitua o arquivo na pasta para tornar as alterações permanentes.

6. Padrões adotados

Catalogação conforme ISAD(G) e NOBRADE. Citações em formato ABNT. IDs no padrão GEDEP-XXX com código de referência BR-GO-GOINFRA-GEDEP-GEDEP-XXX.
